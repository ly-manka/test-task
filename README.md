# Recipe Book

This project is a recipe book application built using Next.js, Tailwind CSS and Node.js with Express.

## Features
- Browse recipes;
- View recipes by: country, category, ingredients;
- View Recipe Info Page;

## Getting Started

### Prerequisites
- Node.js (v22.14.0)
- Git

### Installation
1. Clone the repository:  
   ```bash
   git clone https://github.com/ly-manka/test-task.git

2. Navigate to the backend directory and install dependencies:
   ```bash
   cd recipe-book/backend
   npm install

3. Run the development server for the backend
   ```bash
   npm start

4. Navigate to the frontend directory and install dependencies:
   ```bash
   cd ../frontend
   npm install

5. Run the development server for the frontend
     ```bash
   npm run dev

Now, both servers should be running:
- Backend: http://localhost:5000
- Frontend: http://localhost:3000
